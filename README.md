# 🔐 PrivateAI — Privacy-Focused AI Chatbot

PrivateAI is a Python-based AI chatbot powered by the **Gemini API**, built to explore a more privacy-conscious approach to everyday AI conversations.

## ✨ Features

* 🤖 AI-powered conversational responses
* 💬 Conversation memory for contextual interactions
* 🔐 API key protection using environment variables
* 🐍 Built with Python
* ⚡ Simple and lightweight architecture

## 🛠️ Tech Stack

* **Python**
* **Google Gemini API**
* **python-dotenv**

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/yourusername/PrivateAI.git
cd PrivateAI
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Add your API key

Create a `.env` file:

```env
GEMINI_API_KEY=your_api_key_here
```

**Never commit your `.env` file to GitHub.**

### 4. Run the chatbot

```bash
python gemini_assistant.py
```

## 🎯 Why PrivateAI?

Modern AI assistants are becoming increasingly capable, but this raises an important question:

> **Can we build useful AI while giving greater attention to privacy and user control?**

PrivateAI is an exploration of that idea — focusing not only on what an AI assistant can do, but also on how we think about the data we give it.
